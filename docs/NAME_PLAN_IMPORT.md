# 演出付きネームの取り込み（#246）

原稿を取り込んだ後、「制作する場面・保存した原稿」からネームJSONを選びます。既存コマがある作品への上書きは拒否します。画像・動画生成や外部送信は行いません。

`manga-mac/name-plan/v1` は原稿版の来歴を付ける薄い取り込み用包みです。コマの `sourceRefs` は既存のUnicode scalar範囲、枠は既存の `layout.version=1` を使い、新しいページ描画方式を作りません。ファイルの範囲参照は取り込み時に一致検査した実snapshot IDへ結び付けます。

必須項目: format, source（repo/workId/episodeId/scenes[].id/sha256）, panels（id/sceneId/sourceRefs/characterIds/prompt）, layout。各場面の非見出し段落を原文順に過不足なく参照します。一段落を複数コマへ分割できます。現時点では場面単位の全量取り込みのみです。

作品・原稿SHA-256・参照範囲の順序と完全性・人物ID・既存レイアウトの検査を通してから、未作画コマとして通常の保存処理へ渡します。任意の保存済みproject、メディア、外部アセット参照をインポートする機能ではありません。

演出意図は各コマのpromptとnamePlanの来歴に保持します。台詞、出来事、人物設定を変更しません。本文参照を保持することは、全てを漫画に印字することや、吹き出し組版の完了を意味しません。挿絵Markdownは作画の参考であり台詞ではありません。

作品データは原稿repoで管理し、公開コードrepoや公開CIへ私有原稿を転載しません。今回の試作は第1話・22ページ・88コマ。専用演出モデルの学習や自律エージェント完成を意味しません。

検証: JSON・参照・配置の機械検査とMac GUIの視覚確認を分けて記録します。本PRのマージ、アプリ更新、実Mac受入は別段階です。
