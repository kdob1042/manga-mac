# ネームを作り、漫画制作へ渡す

1. 原稿を取り込む。原稿ブランチと制作する場面を確認する。
2. 「制作する場面・保存した原稿」を開く。必要なら文章単位で対象を選ぶ。
3. 設定済み演出AIでネーム候補を作るか、`manga-mac/name-plan/v2` JSONを選ぶ。旧v1は空の原稿への取り込み互換を維持する。
4. 候補のページ数・原稿の掲載方針・実文字入り仮ネームを確認する。文字溢れや対象外ページとの衝突は修正してから採用する。
5. 「このネーム候補を採用」または「旧稿を残して別初稿に採用」。取込・確認だけでは作画・外部送信・公開しない。
6. 「このネームで制作」。既存の画像モデル／人物参照を使い、確定ページを維持して作画・文字配置・初稿表示へ進む。
7. 局所編集の指示は候補として確認する。枠だけなら画像は再生成しない。コマ内容を変える指示は再ネーム候補にする。手動の枠変更は既存エディタを使い、旧意味計画から巻き戻さない。

固定ページ、別初稿の復元、既存Undoを利用できる。原稿・人物参照・設定が変わった場合は旧漫画を残して再確認へ戻る。元の原稿は編集しない。

視覚QAは画像入力対応接続の設定と、ページ画像送信の明示許可がある場合だけ実行する。機械検査、AIの指摘、人が読む評価を区別する。仮ネームには作画プレースホルダーを用い、完成画像ではない。

ページ内に収まる非重複の凸四角形を使う。自動compilerの斜辺は二つのleaf間、insetは非重複の小コマ。曲線・複雑な重なり・印刷裁ち落としを無断で単純枠へ変換しない。

仕様の正本: [設計・実装計画 §23](IMPLEMENTATION_PLAN.md#23-ネームai-v2と決定論的組版252262)。Mac／実モデル受入は自動試験とは別に確認する。
